# Homepage photo ribbon

Review-only addition prepared from the 17 user-supplied inspection and product images. Every source image is resized proportionally to a common height without cropping, overlays, captions, or generated replacement content. Portrait images remain narrow; landscape images remain wide.

The four binary transport parts concatenate in numeric order into one 4256 x 200 AVIF atlas (23,971 bytes). `build/photo-ribbon.js` validates SHA-256 and serves/emits it as `/photo-ribbon.avif`. The build injects the ribbon immediately below the existing homepage hero without rewriting the original homepage or replacing its slideshow.

Desktop height: 190 CSS pixels. Mobile height: 150 CSS pixels. Motion: left to right at 30 CSS pixels per second. Includes pause/play, previous/next, hover pause, touch browsing, keyboard controls, and reduced-motion support.
