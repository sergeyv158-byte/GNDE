HOW TO UPLOAD
1. Extract this ZIP on your computer.
2. Open the GNDE review branch in GitHub:
   https://github.com/sergeyv158-byte/GNDE/tree/review-pulser-receiver-approved-2026-10-26
3. At the repository root, choose Add file > Upload files.
4. Drag the extracted index.html, case-study-buried-anchor-rods.html, and the
   public folder into the upload area. Preserve the public folder and all
   its subfolders. These files replace matching paths and add the new files.
   The instructions file may be kept locally.
5. Commit the upload to the review branch. Suggested message:
   Update case-study organization, source references, and probe captions
6. After Vercel builds that commit, open its new preview deployment.

The package has not been uploaded to GitHub or deployed to Vercel.
